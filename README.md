One deadpan one-star review of gravity, an everyday essential everyone relies on. A real complaint filed in earnest against a thing that cannot be fixed, with the sting in the last few words: "One star for gravity. It pulls everything down all day, every day, with no breaks, no refunds, and no regard for my knees." (122 characters, one line.)

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt` and prints it. The program is deterministic: every run writes the exact same 122 bytes.

## Why this review

Gravity is an everyday essential nobody can opt out of. The sharpest true grievance is that it never stops pulling — no breaks, no refunds — and the turn lands at the end, on the knees that pay for it daily. Deadpan throughout, one joke, no exclamation marks.
